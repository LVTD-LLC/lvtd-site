# Studio design

Use the fire-heart and LVTD wordmark, warm paper, dark ink, and thin rules. Geist
is served locally for interface text. Use a system serif for collection headings.
Preserve the system dark theme, visible keyboard focus, and the skip link.

Projects, Games, Research, and Blog are always visible in the navigation. Mark
the current collection. Let project names link directly to the work and give
source links descriptive accessible names. Preserve client credits and distinguish
archived projects from active ones.

The homepage uses three illustrated project covers. Geometric line drawings
appear beside headings, with a different motif for each collection. Keep them
decorative and lightweight. Use short hover transitions and honor reduced motion.
Layout and color tokens live in assets/css/app.css. Keep the gallery legible as
compact illustrated rows on phones, with no sideways scrolling.

The games repository bundles the same studio mark into the link back to the
arcade. Individual games retain their own boards, controls, language, and art.
